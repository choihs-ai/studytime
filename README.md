# 엎어둬

폰을 엎어 둔 시간만 순공으로 세는 고등학생용 타이머 웹앱.

https://choihs-ai.github.io/studytime/

- 아이폰은 사파리에서 열고 공유 → 홈 화면에 추가
- 다른 앱 잠금은 잠글시간 앱으로 하고, 엎어둬만 허용 앱으로 둔다
- 기록은 기기의 localStorage(`sungong.v1`)에만 저장된다. 서버 없음
- 날짜는 자정에 바뀐다. 자정을 넘겨 이어서 한 세션은 시작한 날로 친다

## 재는 방법 두 가지

- **엎어 두기**: 기울기 센서로 화면이 바닥을 보는 동안만 센다
- **세워 두기**: 전면 카메라에 얼굴이 보이는 동안만 센다
  - 얼굴이 20초 넘게 안 보이면 멈추고 자리 비움 1번. 그 20초는 순공에서 빼서 자리 비움 시간으로 옮긴다
  - 놓인 자세에서 25도 넘게 기울거나, 사람 자리를 뺀 배경이 크게 바뀌면 폰 든 횟수 1번
  - 다른 폰 보면 멈추기(설정, 기본 켬): 새로 집어 들거나 움직이는 폰이 3초 넘게 보이면 폰 든 횟수 1번. 시작 때부터 있던 폰과 20초 넘게 가만히 놓인 폰은 뺀다
  - 졸면 멈추기(실험, 설정에서 켬): 두 눈을 10초 넘게 감고 있으면 멈추고 졸음으로 옮긴다. 고개를 숙이면 판정하지 않는다
  - 타임랩스: 세션 중 작은 사진을 IndexedDB에 모았다가 30초 안팎의 mp4로 만든다. 만들거나 지우면 사진은 바로 지운다
  - 카메라 영상과 사진은 어디로도 보내지 않는다. `index.html`의 CSP가 외부 요청을 구글 폰트로만 막는다

## 파일

`index.html` 화면 틀, `app.js` 화면과 기록, `camera.js` 세워 두기(얼굴·움직임·졸음 감지, 타임랩스), `style.css`, `sw.js` 오프라인 캐시, `manifest.webmanifest`, `icons/`, `vendor/` 얼굴 인식 모델과 mp4 먹서([vendor/README.md](vendor/README.md))
